title: Standalone Laravel Comment System
date: 2026-02-01
period: "2026"
summary: One Laravel comment system rolled out across all 12 websites, replacing CMS-coupled extensions.
---

Independently built a standalone Laravel comment system, replacing third-party, CMS-coupled extensions and centralising functionality to avoid repeating changes across platforms.

Built an embedded frontend component in plain JavaScript and integrated websites through REST APIs, using a public API key for frontend requests and access tokens for backend requests. Implemented SAML SSO with company email and role-based access for editorial moderators to approve, reject, and manage comments. Readers authenticated on the content platform, which passed their name and email to create commenter records when needed.

Built comment posting, replies, voting, spam filtering, and new-comment notifications. Rolled out across all 12 websites; editorial staff reported easier moderation, alongside an observed increase in quality comments and user engagement.
