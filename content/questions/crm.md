## Question

Tell me about a (Laravel) project you built - (CRM System)

## Answer

### What

One of the projects I built was a standalone CRM system for event ticket sales.

### Situation

Saleforce was our CRM system, but it was not easy to use and not flexible to ticket sales. so we decided to build a standalone CRM system that could be easily maintained and scaled.

### Plan

so we decided to build a standalone CRM system that could be easily maintained and scaled. and I managed the project from scratch to production.

### Action (in order to do that)

- I met with the sales team to discuss the requirements and design the system.
- used blade, tailwind, and alpine.js for the view layer.
- and installed fortify for backend authentication.
- Eloquent ORM and MySQL for the database layer.
- Redis for caching, horizon for background jobs.
- PEST for unit testing
- Coded with Cursor and made accceptance tests on staging environment.
- Deployed the system to our production environment through github webhook and Jenkins.

### Result

The new CRM system was rolled out to our production environment and is stable and reliable, and sales team reported faster, easier call management.
