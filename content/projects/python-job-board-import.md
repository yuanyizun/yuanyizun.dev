---
title: Python Job Board Data Preparation
date: 2019-06-01
summary: Python scripts that prepared employer and third-party job listings for WordPress job-board import.
---

Supported the launch of WordPress job boards by developing Python scripts with Requests and Beautiful Soup to fetch web pages, parse HTML, and extract job listings from authorised employer pages and third-party job platforms.

Mapped listing fields to the job-board plugin’s CSV import format, cleaned text, standardised phone numbers and addresses, and removed duplicates to prepare listings for import.
