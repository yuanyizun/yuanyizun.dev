---
title: AWS Migration and Deployment Modernisation
date: 2020-01-01
period: circa 2019–2020
summary: Migrated brand and event websites to AWS and replaced FTP releases with GitHub CI/CD.
---

Collaborated with a cloud consultancy to migrate approximately 15 brand websites and dozens of event websites from dedicated servers to AWS, including load balancing, Varnish caching, web servers, and CloudWatch monitoring.

Established GitHub source control and CI/CD workflows using a staging EC2 server, Jenkins, GitHub webhooks, and GitHub Actions. Replaced direct FTP releases with pull-request code reviews and staging validation before production deployment, enabling faster releases with less manual coordination, easier rollbacks, and fewer production issues.
