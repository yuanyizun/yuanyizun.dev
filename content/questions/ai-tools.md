## Question

How do you use AI coding tools?

## Answer

I use Cursor for feature development, debugging, refactoring and test generation.

### Action

I keep changes in manageable, testable commits so I can understand and review them.

I inspect the changed files, check that the implementation matches the requirements, and validate the workflow manually or with Playwright

### Result

I treat generated code as my responsibility. If it adds unnecessary complexity, I would change or reject it.
